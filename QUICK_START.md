# Quick Start Guide

## 🚀 Getting Started

```bash
npm install  # Already done
npm start    # Start the server
```

Then open `http://localhost:3000` in your browser.

## 🎯 New Features at a Glance

### Sidebar
- **🌙 Dark Mode** - Toggle light/dark theme
- **📅 Daily** - Open today's note
- **📁 Files Tab** - Browse all notes
- **🏷️ Tags Tab** - View all tags
- **🕒 Recent Tab** - Recently opened notes

### Editor Header
- **Word/Char Count** - Live statistics
- **Save Status** - Auto-save indicator
- **Delete Button** - Remove current note

### Toolbar (Below Header)
- **B** - Bold
- **I** - Italic
- **Code** - Inline code
- **# H1/H2/H3** - Headers
- **• List** - Bullet list
- **1. List** - Numbered list
- **☐ Task** - Task list
- **🔗 Link** - Insert link
- **[[Link]]** - Backlink
- **{ } Code** - Code block

### Preview Header
- **📥 Export** - Export to MD/HTML/PDF
- **🕸️ Graph** - Visual graph view

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl+P` | Quick switcher |
| `Cmd/Ctrl+N` | New note |
| `Cmd/Ctrl+S` | Save note |
| `Cmd/Ctrl+B` | Bold text |
| `Cmd/Ctrl+I` | Italic text |
| `Escape` | Close modal |

## 📝 Markdown Features

### Task Lists
```markdown
- [ ] Incomplete task
- [x] Completed task
```

### Tags
```markdown
This note is about #programming and #javascript
```

### Backlinks
```markdown
See also [[Other Note]]
Or with alias: [[Other Note|custom text]]
```

### Code Blocks
```markdown
\`\`\`javascript
console.log('Hello World');
\`\`\`
```

## 📊 Tabs Explained

### Files Tab
- See all notes in folder structure
- Click folders to expand/collapse
- Click notes to open

### Tags Tab
- See all tags with usage counts
- Click tag to filter notes
- Sorted by popularity

### Recent Tab
- Last 20 opened notes
- Shows "time ago"
- Quick access to recent work

## 🕸️ Graph View

1. Click "🕸️ Graph" button
2. See visual map of connections
3. **Blue** = Current note
4. **Purple** = Linked notes
5. **Gray** = Other notes

## 📥 Exporting

1. Click "📥 Export"
2. Choose format:
   - **Markdown** - Raw .md file
   - **HTML** - Standalone webpage
   - **PDF** - Printable document

## 🎯 Common Workflows

### Daily Journaling
1. Click "📅 Daily"
2. Write today's notes
3. Link to relevant notes with `[[]]`

### Project Planning
1. Create new note with Project template
2. Add tasks with `- [ ]`
3. Tag with `#project #name`

### Research Notes
1. Create note
2. Add backlinks to sources
3. Use tags for categories
4. View graph to see connections

### Meeting Notes
1. Create with Meeting template
2. Add attendees and agenda
3. Create action items as tasks
4. Link to project notes

## 🆘 Troubleshooting

**Notes not loading?**
- Check authentication
- Refresh page
- Check console for errors

**Export not working?**
- Libraries loaded from CDN
- Check internet connection
- Try different browser

**Graph view blank?**
- Create some backlinks first
- Link notes with `[[]]`
- Needs connections to show
